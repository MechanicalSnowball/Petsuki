# About Petsuki

This is a little personal project that I choose to practice learning Rust. It was made for no other purpose than learning and paying tribute to one of my favorite games. It also makes use of raylib for handling all of the graphical aspect.

## Special thanks

To Sierpinski Simon on itch.io or Origami Yume Nikki on YouTube, their (far better) implementation of this idea was my inspiration to take on this project.
